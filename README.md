# Task-Manager

A simple command-line based Task Manager built using Python.
It allows users to add, view, and delete tasks easily.

---

##  Features

*  View all tasks
*  Add new tasks
*  Delete tasks
*  Tasks saved in file (persistent storage)
*  Simple and beginner-friendly logic

---

## 🛠️ Tech Stack

* Python

---

## ▶️ How to Run

1. Make sure Python is installed
2. Run the following command in terminal:

```
python main.py
```
